# help page (one entry per paragraph)
Use Network Type NCM (Windows 11) or RNDIS (Windows 10/11). ECM has no Windows driver.	网络类型请选 NCM(Windows 11)或 RNDIS(Windows 10/11)。ECM 在 Windows 上没有驱动。
Windows gets 192.168.7.2 automatically, the device is 192.168.7.1.	Windows 会自动获得 192.168.7.2,设备地址是 192.168.7.1。
Share the PC's Internet with the device:	让设备使用电脑的网络:
 1. Plug in USB, set USB Network to ON (+Internet).	 1. 插上 USB 线,把 USB 网络设为 开(+上网)。
 2. Copy share-internet-windows.bat and share-internet-windows.ps1 from the SD card folder Tools/m21/USB Mode.pak/host-tools to the PC (turn on USB Storage, or use a card reader).	 2. 把 SD 卡里 Tools/m21/USB Mode.pak/host-tools 下的 share-internet-windows.bat 和 share-internet-windows.ps1 拷到电脑(打开 USB 存储,或用读卡器)。
 3. Double-click share-internet-windows.bat and allow the administrator prompt. The script finds the USB adapter and shares your Wi-Fi/Ethernet with it.	 3. 双击 share-internet-windows.bat 并允许管理员权限。脚本会找到 USB 网卡,并把你的 Wi-Fi/网线共享给它。
 4. On the device: adb shell, then ping 8.8.8.8 and ping www.baidu.com.	 4. 在设备上:adb shell,然后 ping 8.8.8.8 和 ping www.baidu.com。
Run the .bat again after changing Network Type or re-plugging the cable (Windows creates a new adapter). To stop: share-internet-windows.bat off	更换网络类型或重新插线后要再运行一次 .bat(Windows 会新建网卡)。停止共享:share-internet-windows.bat off
If it does not work, run usb-diag-windows.bat (same folder) and look at usb-diag.txt.	如果不通,运行 usb-diag-windows.bat(同一文件夹)并查看 usb-diag.txt。
USB Serial (ACM) appears as a COM port in Device Manager (Ports).	USB 串口(ACM)会在设备管理器的“端口”里显示为 COM 口。
Use Network Type ECM or NCM. RNDIS is not supported on macOS.	网络类型请选 ECM 或 NCM。macOS 不支持 RNDIS。
A new network interface appears (System Settings > Network). The Mac gets 192.168.7.2 automatically, the device is 192.168.7.1.	系统设置 > 网络里会出现新网口。Mac 会自动获得 192.168.7.2,设备地址是 192.168.7.1。
Share the Mac's Internet with the device:	让设备使用 Mac 的网络:
 2. Copy share-internet-macos.sh from the SD card folder Tools/m21/USB Mode.pak/host-tools to the Mac.	 2. 把 SD 卡里 Tools/m21/USB Mode.pak/host-tools 下的 share-internet-macos.sh 拷到 Mac。
 3. In Terminal run:	 3. 在“终端”里运行:
    (when the uplink is not auto-detected, e.g. with a VPN: sudo sh share-internet-macos.sh on en0)	    (如果没能自动识别出上行网口,例如开了 VPN:sudo sh share-internet-macos.sh on en0)
 4. On the device: adb shell, then ping 8.8.8.8	 4. 在设备上:adb shell,然后 ping 8.8.8.8
Run it again after changing Network Type or re-plugging. To stop:	更换网络类型或重新插线后要再运行一次。停止共享:
USB Serial (ACM) appears as /dev/cu.usbmodem*; use: screen /dev/cu.usbmodem* 115200	USB 串口(ACM)在 Mac 上是 /dev/cu.usbmodem*,用法:screen /dev/cu.usbmodem* 115200
Use Network Type ECM or NCM (RNDIS also works). The PC gets 192.168.7.2 automatically, the device is 192.168.7.1.	网络类型请选 ECM 或 NCM(RNDIS 也可以)。电脑会自动获得 192.168.7.2,设备地址是 192.168.7.1。
 2. Copy share-internet-linux.sh from the SD card folder Tools/m21/USB Mode.pak/host-tools to the PC.	 2. 把 SD 卡里 Tools/m21/USB Mode.pak/host-tools 下的 share-internet-linux.sh 拷到电脑。
 3. In a terminal run:	 3. 在终端里运行:
    (or name the uplink interface: sudo sh share-internet-linux.sh on wlan0)	    (或指定上行网口:sudo sh share-internet-linux.sh on wlan0)
To stop:	停止共享:
USB Serial (ACM) appears as /dev/ttyACM0; use: screen /dev/ttyACM0 115200	USB 串口(ACM)在 Linux 上是 /dev/ttyACM0,用法:screen /dev/ttyACM0 115200
