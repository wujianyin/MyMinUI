# UI languages (i18n)

> 中文版: [I18N.zh-CN.md](I18N.zh-CN.md) | Back to [README.md](README.md)

MyMinUI-M22Pro can switch its interface between **English** and **简体中文 (Simplified Chinese)**. Everything on screen is covered:
the MinUI desktop, the in-game menu (minarch), the shipped tools and USB Mode. More languages can be added without recompiling.

## For users

- **First start:** if no language has been chosen yet, a picker ("Language / 语言") appears before the desktop. Use Up/Down and **A** to confirm.
  This screen cannot be skipped with B.
- **Change it later:** *Tools > Language* (shown as *语言* in Chinese). Pick a language and press A. The desktop restarts and uses it right away; **B** goes back without changing.
- The choice is stored in `/.userdata/shared/language` (for example `zh_CN` or `en`). Delete this file to see the first-start picker again.
- Button labels (`A`, `B`, `MENU` ...) are never translated, only the hint words next to them (`BACK`, `OKAY` ...).
- Config files keep English values (for example `Lenient` in `minarch.cfg`); translation happens only when text is drawn, so switching language never breaks saved settings.
- Chinese needs the CJK font replacements, which the release zip already contains ([cjkfont README](workspace/m21/other/cjkfont/README.md)).

### Tool state display

The four tools `ToggleSleepMode`, `ToggleSeekPageTriggers`, `ToggleHideState` and `ToggleHideBOXARTifState` show their current value in the list as `name: value`:

| Tool | What it does | Values |
|---|---|---|
| `ToggleSleepMode` | What the power button does | `Sleep` / `Power off` |
| `ToggleSeekPageTriggers` | Which buttons jump a page in long lists | `L2/R2` / `Left/Right` |
| `ToggleHideState` | Hide the save-state preview image (Fancy list mode) | `On` / `Off` |
| `ToggleHideBOXARTifState` | Hide the box art when a save-state preview exists (Fancy list mode) | `On` / `Off` |

Fancy mode is the third list mode, selected on the INFO page with Up/Down.

## For developers

### How it works

- Source strings in the code are **English**. Wrap every user visible string with `TR("...")` (declared in `workspace/all/common/utils.h`).
  `TR` returns the translation, or the same string if there is none, so a missing translation is harmless.
  (The usual `_()` name cannot be used: `api.c` has a variable called `_`.)
- `I18N_init()` runs at the start of `GFX_init()`. It reads the language code and loads two catalogs into a hash table:
  1. the shared catalog `/.system/res/lang/<code>.txt`;
  2. the catalog of the running tool: `$PAK_DIR/lang/<code>.txt` (falls back to `./lang/`). Tool entries override shared ones.
- English (`en`, or no language file) loads nothing, so there is zero cost.
- Hints passed to `GFX_blitButtonGroup` are translated automatically. Desktop entries that are paks are named by
  `I18N_getPakName(pak_path, name)`, which reads *that pak's own* catalog (cached), then the shared one. This is why a tool's translated name lives inside its own pak.
- API summary: `I18N_init`, `I18N_get`/`TR`, `I18N_getLanguage`, `I18N_getPakName`, `I18N_isLanguageChosen`, `I18N_listLanguages`, `I18N_setLanguage`.

### Catalog format

UTF-8 text, one entry per line: `English<TAB>translation`.

```
#name: 简体中文
# comment
BACK	返回
Sleep	休眠
No cheat file loaded	未加载作弊码文件
Press any button\nto continue	按任意键\n继续
```

- `#name:` gives the name shown in the language picker. Other lines starting with `#` are comments.
- `\n` is a line break, `\t` a tab, `\\` a backslash.
- Keep `printf` placeholders (`%s`, `%i`, `%d`, `%llu`) exactly as in the English text. The English string is the lookup key, so it must match the source character for character.
- An empty translation means "not translated". Lines are limited to 2047 bytes.

### Where strings live

| Strings of ... | File |
|---|---|
| Button hints, MinUI desktop, in-game menu, core options and descriptions, controls, shortcuts, save messages | `skeleton/SYSTEM/res/lang/<code>.txt` |
| One tool (including its display name on the desktop) | `skeleton/EXTRAS/Tools/m21/<Tool>.pak/lang/<code>.txt` |
| USB Mode (all pages and the help text) | `skeleton/EXTRAS/Tools/m21/USB Mode.pak/lang/<code>.txt` |

A tool's `launch.sh` must export `PAK_DIR` (or `cd` into the pak) for its catalog to be found; USB Mode does `export PAK_DIR`.
Tool programs need nothing else: calling `GFX_init()` is enough.

### Add a language

1. Copy `skeleton/SYSTEM/res/lang/zh_CN.txt` to `<code>.txt` (for example `de.txt`; the code may contain letters, digits, `_` and `-`), change the `#name:` line and translate the right-hand column.
2. Do the same for each `Tools/m21/*.pak/lang/` (a tool without a catalog stays English).
3. Make sure the UI font has the glyphs of that language (the shipped font covers Latin, GB2312 and kana only).
4. Copy the files to the card, or rebuild with `package.sh`. The new language shows up in *Tools > Language* automatically (every `*.txt` in `/.system/res/lang/` is listed).

### First-start flow

`skeleton/SYSTEM/m21/paks/MinUI.pak/launch.sh` runs `language.elf --first` once, before the main loop, when `/.userdata/shared/language` does not exist.
After a tool exits, the loop restarts `minui.elf`, so the new language is picked up. To test the first start on a running device:

```sh
adb shell 'echo "language.elf --first" > /tmp/next; kill -9 $(ps | grep "minui.elf" | grep -v grep | awk "{print \$1}")'
```
